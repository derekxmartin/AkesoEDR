# Security policy

This repository is maintained as a research or development project. The default branch is the current development target; older snapshots have no promised security support.

## Report a vulnerability privately

Use GitHub's **Security → Report a vulnerability** for this repository when available: https://github.com/derekxmartin/AkesoEDR/security/advisories/new.

If private reporting is unavailable, use the contact route on [the maintainer's profile](https://github.com/derekxmartin) to request a private channel before sending sensitive details. Do not open a public issue containing credentials, personal data, exploitable details, or customer information.

Include the affected commit, environment, impact, and a minimal reproduction using synthetic data. A response time, bounty, or supported production deployment is not promised.

## Safe testing

Test only in environments you own or have permission to assess. Use disposable local accounts and synthetic fixtures. Keep tokens, real telemetry, private keys, and production configuration out of commits and issue attachments. Rotate any exposed credential; deleting a file does not revoke it or remove old Git history.
